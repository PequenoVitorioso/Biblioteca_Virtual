# Minha Estante

Protótipo de biblioteca pessoal feito com HTML, CSS e JavaScript. As obras, os desejos, o progresso e o perfil são salvos no navegador.

## Como abrir

É preciso ter Node.js instalado. Na pasta do projeto, execute:

```powershell
npm.cmd run dev
```

Abra [http://localhost:5173](http://localhost:5173). Use esse endereço em vez de abrir os arquivos HTML diretamente, para que todas as páginas compartilhem os mesmos dados locais.

## Testes

```powershell
npm.cmd test
```

O perfil é local e não cria uma conta online. O botão de restauração na página Perfil recupera os dados de exemplo da coleção e do progresso.
